## 2. 核心異動說明
為了將愛車支出記帳小程式升級為符合 Apple 風格審美、解決手機窄螢幕上的資料截斷，並大幅改善設定畫面的互動體驗，進行了以下重構與優化：
1. **類別設定位置調整**：將「類別設定」從主畫面移除，移入右上角「設定」對話框的最下方，精簡主畫面空間。
2. **明細表分頁與 iOS 導覽列**：將花費明細表獨立為 SPA 分頁。主畫面提供「查看用車花費明細」跳轉按鈕，明細頁頂部設計為 iOS 經典 Navbar，左側為 `< 返回` 按鈕，右側為 `匯出` 按鈕。
3. **明細表年份分組 (GroupBy Year) 與 MM/DD 顯示**：表格依年份分組插入 `📅 [年份] 年` 的分組分隔線。表格內日期縮短為 `MM/DD`（如 `02/06`），大幅釋放水平空間，徹底解決類別與備註在手機上被截斷的問題。
4. **點選行彈出編輯**：移除表格內擁擠的輸入框。明細表改為唯讀純文字，點擊行任意處會彈出「編輯花費對話框」供用戶修改。
5. **預設設定配置區**：在程式碼最上方提供 `DEFAULT_GAS_API_URL` 常數，貼上後手機即可免去手動輸入網址的麻煩。
6. **設定視窗 Bug 修復**：修復了背景同步失敗時設定視窗反覆彈出的問題，改為在 Modal 內以紅字顯示錯誤原因與排查指引。

## 3. 本期凍結事項
- 🔒 **新增凍結**：網頁部署於 GCS（Google Cloud Storage）作為靜態網頁，不使用任何 Python 後端服務。
- 🔒 **新增凍結**：不將 Google Sheets 試算表 ID 寫死於程式碼，改以 GAS Web App 連線，並由自訂驗證 Token 保護，敏感資訊（如密碼）不寫死。
- 🔒 **新增凍結**：加油里程數自動編碼為 `[里程 km] 備註` 格式，維持後端 Sheet 的現有相容性，免去動態加欄位的不確定性。
