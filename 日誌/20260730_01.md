## 🛠️ 核心變更與功能說明

### 1. 記帳系統主程式升級：展示模式 (Demo Mode v3.2)
- **設計緣由**：為配合簡報中「即時動態展示小程式操作」的需求，避免與後端 Google Apps Script API 的網路請求在展示時失敗或延遲。
- **實作邏輯**：當在系統設定（`cfgApiUrl` 或 `cfgToken`）輸入為 `"demo"` 時，程式將自動偵測並攔截所有網路請求，改為載入本地預設的 Mock 交易與分類數據。同時，在點擊「確認記帳」時會直接本地模擬寫入，成功清除輸入框，並**完美觸發 Apple 風格的打勾成功動畫**，為使用者提供無連線障礙的完整體驗。

### 2. 紅白黑漫畫風格演示稿 (Hyperframes 簡報)
- **視覺美學**：採用強烈的紅白黑（Red, Black, White）三色美式/日式漫畫風格。設計包含粗線條分鏡框、大膽的標題文字描邊、紅色速度線飾條，以及背景微弱的漫畫網點（Halftone Dots）。
- **圖片素材**：使用 `generate_image` 生成了 4 張 16:9 漫畫風格主視覺插圖：
  - `slide1.jpg`：HRV 鋪陳畫面，代表專案介紹。
  - `slide2.jpg`：手持 iPhone 的交易成功畫面，代表極簡視覺。
  - `slide3.jpg`：汽車里程表 `125,000 km` 與預算指針，代表里程解析與預算控制。
  - `slide4.jpg`：安全雲端與锁頭，代表無後端 GAS 直連的安全架構。
- **TTS 語音生成**：使用 Kokoro-82M 中文女聲模型 (`zf_xiaobei`) 為簡報的四個 Slide 依演講稿分別生成 `slide1.wav` 至 `slide4.wav`。
- **字幕與音軌高精度同步**：在 `presentation/index.html` 中實作了特殊的音軌同步機制，在 GSAP 時間軸的 `onUpdate` 監聽器中實時比對 `currentTime`，確保在簡報預覽拉動進度條、暫存、倒帶時，聲音與畫面字幕均能 100% 完美對齊。

### 3. postMessage 確定性自動化操作演示 (修復 file:// 跨域限制)
- **問題診斷**：由於現代瀏覽器的安全性政策，若使用者直接以雙擊方式在 `file://` 協議下打開 `presentation/index.html`，同源政策會封鎖簡報網頁對 `<iframe>` 內部的 `contentWindow.document` 存取與操作，造成模擬展示完全失效（黑屏或卡死）。
- **重構方案**：
  1. 在 `presentation/app.html` 內加入監聽 `message` 事件的 `postMessage` 接收器。
  2. 當接收到 parent 傳送的簡報當前播放秒數 `time` 時，由 `app.html` 內部 JS 自行根據時間進行狀態機對齊（包括開啟 Modal、填入 demo 憑證、點擊快捷鍵、填寫里程及提交表單觸發打勾動畫、切換至明細頁）。
  3. 將 `presentation/index.html` 的 iframe 操作完全重寫為精簡的 `postMessage({ action: 'syncTime', time })` 發送器。
- **成果**：實現了跨域與無伺服器的相容，不論直接雙擊 `presentation/index.html` 或起本地伺服器，自動操作展示均 100% 完美運作。
