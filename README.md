# 🚗 愛車支出記錄系統 (Car Expense Tracker)

輕量化、純前端的愛車支出記錄系統（HTML/CSS/JS）。採用 **Apple iOS 暗色模式** 視覺風格設計，支援 iOS SPA 跨頁明細、用車預算追蹤、里程數自動記憶與展示模式。

---

## 🍎 核心特色

- **Apple 極簡暗色美學**：採用 iOS 經典純黑背景（`#000000`）與深灰卡片質感，搭配金色強烈對比。
- **里程數記憶與維護**：自動記憶上一次輸入的里程數，並自動反向解析圖表與保養週期。
- **用車快捷輸入鍵**：提供常用的加油、保養、洗車與停車快捷備註及金額加總。
- **開箱即用展示模式 (Demo Mode)**：預設載入體驗模式，無需連線即可直接體驗視覺圖表與全功能。
- **無縫連線 Google 試算表**：可輸入個人的 Google Apps Script (GAS) Web App 網址與 Token，將資料安全同步至您的 Google Sheets。

---

## 🚀 快速開始

1. 開啟 GitHub Pages 網址直接使用。
2. 點擊右上角 **⚙️ 設定** 按鈕：
   - 預設模式為 `demo`（可直接試用全功能）。
   - 若要連結個人試算表，填入您的 **GAS Web App URL** 與 **Token** 即可完成同步。
